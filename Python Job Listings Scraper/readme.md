Python Job Listings Scraper

A Python web scraper that collects job listings from the Fake Python Jobs website.

Project URL

https://realpython.github.io/fake-jobs/

Features

Scrapes job titles
Extracts company names
Extracts job locations
Extracts job detail page URLs
Saves results to a CSV file
Handles missing fields

Technologies Used

Python
Requests
BeautifulSoup
CSV

Installation

Install the required libraries:


pip install requests beautifulsoup4
